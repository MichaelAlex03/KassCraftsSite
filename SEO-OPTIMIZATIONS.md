# SEO Optimizations for Kassy's Krafts

This document explains all the SEO improvements made to your website and why they matter.

## 1. Enhanced Metadata (layout.tsx)

### Title Tag
**Before:** "Create Next App"
**After:** "Kassy's Krafts | Custom Hand-Painted Banners & Designs"

**Why:** The title tag is one of the most important SEO factors. It appears in search results and browser tabs. Including your business name and main keywords helps search engines understand what your site is about and improves click-through rates.

### Meta Description
**Added:** Descriptive 155-character summary of your business

**Why:** Meta descriptions appear in search results below the title. A compelling description with keywords increases click-through rates. Google often uses this as the snippet shown in search results.

### Keywords Array
**Added:** Targeted keywords like "custom banners", "hand-painted banners", "personalized banners"

**Why:** While less important than before, keywords still help search engines categorize your content. They should reflect what customers actually search for.

## 2. Open Graph Tags

**Added:** Complete Open Graph metadata including:
- Title, description, and URL
- Image with proper dimensions (1200x630 - optimal for social sharing)
- Site name and locale

**Why:** Open Graph tags control how your site appears when shared on social media (Facebook, LinkedIn, etc.). Without them, social platforms may display incorrect or missing information. This increases social engagement and brand visibility.

## 3. Twitter Card Tags

**Added:** Twitter Card metadata with large image format

**Why:** Similar to Open Graph but specifically for Twitter/X. The "summary_large_image" card type makes your links stand out in feeds with eye-catching visuals, increasing engagement.

## 4. Robots Meta Tags

**Added:** Instructions for search engine crawlers

**Why:** These tags tell search engines:
- `index: true` - Include this page in search results
- `follow: true` - Follow links on this page
- `max-image-preview: large` - Allow large image previews in search results
- This gives you control over how search engines interact with your site

## 5. Structured Data (Schema.org JSON-LD)

**Added:** LocalBusiness schema markup with:
- Business name, description, and contact info
- Price range ($35-$75)
- Payment methods accepted
- Social media links
- Operating hours

**Why:** Structured data helps search engines understand your business details. This can result in:
- **Rich snippets** in search results (showing prices, ratings, hours)
- **Google Business Profile integration**
- **Better local SEO** - helps you appear in "near me" searches
- **Voice search optimization** - smart assistants use this data

Example: When someone searches "custom banners near me", Google can show your price range and hours directly in results.

## 6. Improved Image Alt Text

**Before:** `alt="banner"`
**After:** `alt="Kassy's Krafts custom hand-painted banner showcasing colorful personalized design work"`

**Why:**
- **Accessibility** - Screen readers describe images to visually impaired users
- **SEO** - Search engines can't "see" images, they read alt text to understand content
- **Image Search** - Better alt text = better visibility in Google Images
- **Backup** - If image fails to load, alt text displays instead

## 7. Priority Loading

**Added:** `priority` attribute to hero image

**Why:** Tells Next.js to load the hero image first since it's "above the fold" (visible without scrolling). This improves:
- **Largest Contentful Paint (LCP)** - Core Web Vital metric
- **Perceived performance** - Site feels faster to users
- **SEO rankings** - Google considers page speed in rankings

## 8. ARIA Labels for Accessibility

**Added:** `aria-label` attributes to buttons and `aria-hidden="true"` to decorative icons

**Why:**
- **Accessibility** - Screen readers announce button purposes clearly
- **SEO** - Google favors accessible sites
- **User Experience** - Better for all users, especially those with disabilities
- **Legal Compliance** - ADA compliance reduces legal risks

## 9. Robots.txt File

**Created:** `/public/robots.txt`

**Why:** This file tells search engine crawlers:
- Which pages to crawl and which to skip
- Where to find your sitemap
- Crawl rate preferences
- Prevents crawling of API routes (saves server resources)

## 10. XML Sitemap

**Created:** `/app/sitemap.ts` (auto-generated by Next.js)

**Why:** Sitemaps are like a roadmap for search engines:
- Lists all important pages on your site
- Shows when pages were last updated
- Indicates page priority and update frequency
- Helps search engines discover and index pages faster
- Especially important for new websites

## 11. Semantic HTML Structure

**Verified:** Proper heading hierarchy (H1 → H2 → H3)

**Why:**
- Search engines use headings to understand content structure
- Each page should have one H1 (main topic)
- Subsequent headings should follow logical order
- Improves accessibility and SEO simultaneously
